# Каталог книг

Приложение получает каталог из REST API и позволяет добавлять книги.

Ресурс: `books`.

Поля книги:
- `title` — название;
- `author` — автор;
- `genre` — жанр;
- `year` — год издания, число.

`id` новой книги создаётся сервером.

## Запуск

Нужны Node.js 22.12 или новее, npm и VS Code с расширением Live Server.

Из корня проекта:

```bash
cd backend
npm install
npm run dev
```

Оставьте API запущенным. Откройте `frontend/index.html` через Live Server.

Endpoint: `http://localhost:3000/books`.

- `GET /books` — получить каталог.
- `POST /books` — добавить книгу в `backend/db.json`.
- `PATCH /books/:id` — изменить выбранные свойства книги.
- `DELETE /books/:id` — удалить книгу после подтверждения.

Интерфейс показывает загрузку, результат, пустой каталог и ошибку.
Кнопка «Обновить» повторяет загрузку.
Форма очищается только после успешного сохранения.
