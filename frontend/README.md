# Frontend

Откройте `index.html` через VS Code → **Open with Live Server**.

Backend должен одновременно работать на `http://localhost:3000/books`.

Страница получает каталог через `GET` и добавляет книги через `POST`.
Показывает загрузку, результат, пустой каталог и ошибку.
Кнопка «Обновить» повторяет загрузку.
